# Vanessa Owusu Ansah — academic website

This is a clean, static GitHub Pages website. It uses only HTML, CSS, and a small JavaScript file, so no installation or build step is required.

The navigation includes About, Research, Teaching, QuantBridge, and CV. The day/night switch remembers the visitor's preference on their device.

## Publish with GitHub Desktop

1. Copy `index.html`, `style.css`, `script.js`, and `favicon.svg` into the root of your existing `VanessaOwusuAnsah.github.io` repository.
2. Remove the old site files and any files belonging to the previous template owner.
3. In GitHub Desktop, review the changes, write a summary such as `Personalise academic website`, click **Commit to main**, then click **Push origin**.
4. GitHub Pages should update at `https://vanessaowusuansah.github.io/` after a short delay.

## Add your portrait

Place a square or portrait photograph named `profile.jpg` in the same folder. The website will automatically replace the `VOA` monogram with that image. A high-resolution JPG cropped around the head and shoulders works best.

## Add a downloadable CV later

Place your PDF in this folder (for example, `Vanessa_Owusu_Ansah_CV.pdf`) and replace the email link in the CV section of `index.html` with:

```html
<a class="button primary" href="Vanessa_Owusu_Ansah_CV.pdf" target="_blank">Download CV</a>
```

## Personal details to review

- Research project titles and descriptions
- Teaching areas and teaching philosophy
- Any social links you want to add
- Degrees, appointments, awards, and presentations for the CV tab

The site intentionally contains no inherited papers, portrait, CV, or links from the original template owner.
